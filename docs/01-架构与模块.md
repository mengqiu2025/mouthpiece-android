# 01 · 架构与模块

## 1.1 整体形态

单 Activity + Jetpack Compose，**没有 Fragment、没有 XML 布局**。

`res/` 里只有 4 个 AndroidX 通知栏自带布局，App 自己的界面 100% 由 Compose 代码绘制。
`res/` 也**没有 `values/strings.xml`** —— 所有中文文案都硬编码在 Kotlin 源码里（这也是为什么字符串能从 dex 里直接挖出来）。

## 1.3 包结构（应用自身共 310 个类）

### `com.mouthpiece.app` — 入口与装配

| 类 | 职责 |
| --- | --- |
| `MouthpieceApp` | `Application`。`onCreate()` 调 `ServiceLocator.init()` 并同步推送计划；`onTrimMemory(20)` 时 `flushHistory()` |
| `MainActivity` | 唯一 Activity。`EdgeToEdge.enable()`；解析 `ACTION_SEND` / `ACTION_PROCESS_TEXT` 把外部文本送进输入框；`launchMode="singleTask"` |
| `ServiceLocator` | 手写依赖容器（全部静态字段）。持有 settings / personas / history / repository / cardRenderer，并提供 `sharedText` 冷流 |
| `AppInfo` | 版本常量：`CHANNEL = "内测版"`、`versionLabel = "内测版 v0.1.4"`、`buildNumber = 5` |

## 1.4 依赖注入

**没有 Hilt、没有 Koin**。`ServiceLocator` 是一个纯静态单例：

```kotlin
object ServiceLocator {
    private var ready = false
    private lateinit var settings: SettingsStore
    private lateinit var personas: PersonaStore
    private lateinit var history: HistoryStore
    private lateinit var repository: ReplyRepository
    private lateinit var cardRenderer: ShareCardRenderer

    private val sharedTextChannel = Channel<String>(Channel.BUFFERED)
    val sharedText: Flow<String> = sharedTextChannel.receiveAsFlow()

    fun init(context: Context) {
        if (ready) return
        val ctx = context.applicationContext
        settings = SettingsStore(ctx)
        personas = PersonaStore(ctx)
        history  = HistoryStore(ctx)
        repository = ReplyRepository(
            settingsProvider = { settings.settings.value },
            ai = OpenAiCompatGateway { settings.settings.value },
        )
        cardRenderer = ShareCardRenderer(ctx)
        ready = true
        PushNotifier.ensureChannel(ctx)
    }
}
```

`MainViewModel` 等通过 `VmFactory` 从 `ServiceLocator` 取依赖。

## 1.5 应用生命周期要点

- `MouthpieceApp.onCreate()` → 装配依赖 + `syncPushSchedule()`（不强制）
- `MouthpieceApp.onTrimMemory(TRIM_MEMORY_UI_HIDDEN=20)` → `flushHistory()`（把内存中的历史刷盘）
- `MainActivity.onCreate()` → 若 `savedInstanceState == null` 且 Intent 带分享文本，则 `emitSharedText()`
- `MainActivity.onNewIntent()` → 同样处理（`singleTask` 保证复用实例）
